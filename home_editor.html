S E N T I N E L A — Editor da Página Inicial

Escolha qual período aparece em index.html sem mexer em código — depois é só colar o resultado no GitHub.

1Carregar os períodos disponíveis

Abra data/historico/manifest.json no repositório, copie o conteúdo e cole aqui. Se ainda não existir nenhum mês arquivado, só vai aparecer a opção "Acumulado".

2Escolher o período da home

"Acumulado" soma TODAS as semanas já coletadas até agora. Os outros são meses específicos, já arquivados em historico/.

3Copiar pro GitHub

Copie o texto abaixo e cole no arquivo data/config_home.json do repositório (GitHub → abrir o arquivo → ✏️ Edit → apagar tudo → colar → Commit changes). Na próxima vez que o dashboard for gerado (automático ou manual), a home passa a mostrar esse período.
