Como usar esta página

Férias: confira o que o sistema detectou. “Está certo” valida; “Ajustar datas” muda o período; “Não é férias” vira falta.

Dias sem trabalho: escolha o que foi cada período (ausência justificada, folga, meia folga) ou confirme falta. Sem classificar, o dia conta como falta.

Novo lançamento: use quando você já sabe do dia antes de o sistema detectar.

Ajuste de pontos: corrige a nota por um motivo curto. Aparece no Extrato como “Ajuste manual”. Dá para desfazer.

Equipe parada: chuva, reunião, treinamento, levantamento de índice, ovitrampa, recuperação de casas.

Contestações: pedidos dos agentes. Aceite (e dê pontos, se for o caso) ou recuse com uma resposta curta. O agente vê a resposta usando o código dele.

Fechar mês: só libera com a lista toda marcada. Depois de fechado, o mês não muda sozinho.

Depois de qualquer ação, o site se atualiza sozinho em alguns minutos. Em “Histórico” você vê se já foi aplicado. Nunca escreva CID, diagnóstico ou atestado: o site é público.

Dica: no celular, use “Adicionar à tela inicial” para instalar como aplicativo. O PIN só fica guardado enquanto o app está aberto.
